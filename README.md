# eve-dogma-lab

EX-CT architecture lab: several independent implementations of the EVE dogma attribute/modifier engine,
same stateless CLI contract as [eve-dogma-rs](https://github.com/EX-CT/eve-dogma-rs), scored on a shared
bench against Pyfa. Each variant lives on its own branch/directory (`variant-a/`, `variant-b/`, …).
